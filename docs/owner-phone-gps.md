# Bus tracking from an owner phone

1. Restart the TransitLK Backend task after this update, then reload Expo Go.
2. Sign in with the approved owner account that owns the registered bus.
3. Open Owner dashboard → Fleet routes and select its registration plate.
4. While physically on that bus, tap **I am on this bus · Start sharing GPS**, allow location permission, and keep the fleet screen open.
5. A passenger on another device can search that bus and open Track. The bus icon, GPS speed, fix time and estimated road ETA update while the source is available.
6. Tap **Stop sharing bus GPS** to end sharing. Closing the fleet screen or backgrounding the app also stops the sender. If the network prevents a stop request, the last position expires after 60 seconds.

The publishing button explicitly shares this phone's coordinates and speed with passengers. It does not share a passenger's location as a bus. Only approved owners can publish for their own fleet, checked against the authenticated session on every request. Coordinates are saved as the latest sample on that bus, not as a historical location trail.

Samples must be within 30 seconds, have accuracy within 100 metres, and be newer than the prior sample. Speed is reported by the phone in metres/second and displayed as km/h; unknown speed stays unavailable. The app sends at most one fix per five seconds and passengers poll every five seconds. ETA is a road-routing estimate to the selected destination, recalculated every 30 seconds; it does not include live traffic or actual dwell time. Scheduled arrival and listed seats are separate from GPS.

No fake bus position, random speed, or countdown ETA is generated by the passenger bus tracking sheet. Without a feed, the UI shows GPS OFFLINE; stale data is hidden. The separate demonstration journey module remains labelled Demo.

Use Expo Go for the local phone GPS sender. HTTP LAN webpages cannot request browser GPS; use HTTPS for a hosted sender. This implementation supports foreground sharing only, not background or lock-screen tracking.

Validation: 90 backend/routing tests pass, TypeScript passes, and Metro iOS, Android and web bundles compile. Tests cover ownership, missing permissions, invalid fixes, old/future samples, ordered updates, stopping, stale data and unavailable speed. Actual travel and physical-device permission acceptance require the owner's device.
